# Agent Guidelines: Project 2

Instructions for automated tooling and AI assistants working in this directory.

## Environment

* Always use the local virtual environment:
  * Windows: `.venv\Scripts\python.exe`
  * Unix / macOS: `.venv/bin/python`
* Dependencies are listed in `requirements.txt`.

## LaTeX Compilation

* The main report file is `main.tex`.
* To compile locally, run `pdflatex main.tex` twice so cross-references and table numbering resolve.
* Keep edits targeted to designated question blocks in `main.tex`.
